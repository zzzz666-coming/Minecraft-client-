# Minecraft Client

Fabric client mod for **Minecraft Java 1.21.11**.

## Current module

- **Training Target Indicator**: detects a living entity under the crosshair and displays its name.
- Toggle with **K** by default. Rebind it in Minecraft's Controls menu.
- Client-side only; it does not click, attack, or automate combat.

## Build

Requires Java 21 and Gradle.

```sh
gradle build
```

The mod jar is generated in `build/libs/`.
